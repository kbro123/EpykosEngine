Test-only fixtures, not engine API: seeded books (`m1_book`), their oracle pricers and tables (`m1_price`, `m1_reference`), record helpers (`record_m1`), forward-mode helpers (`m1_tangent`: tangent, Jacobian by Dual<1> passes and by one Dual<12> pass), the M1 book on the differential tester (`m1_differential`: the M2 state ball, the reference and the D26 scales) and the near-miss shapes fixture (`nearmiss_shapes`: op trees that differ in one respect a signature may overlook, the gate fixture behind the mutation harness, D32), namespace `epykos::fixtures`.
Everything is generated from the seed in `docs/WORKLOADS.md`; there are no data files. Milestone names appear here only as fixture names.
No engine header (`include/epykos/<component>/`) may include a header from this directory; tests, benches and `bench/hand/` may.
